# AI and History Conference 2026 報告要約の編集・公開手順

公開用の原稿は[日本語版](../src/pages/notes/ai-history-2026.md)と[英語版](../src/pages/en/notes/ai-history-2026.md)。各言語の研究活動ページから案内する。英語版も公式の英語資料から直接執筆し、各主張・話者・時刻を原資料と照合する。

## 1. 掲載範囲を確定する

[公式の報告一覧](https://proflouishyman.github.io/ai_conference_2026/talks/)を起点に、掲載順、公式番号、原題、登壇者を記録する。初版の2026年11月20日にはS01～S11、S13～S28の27件を確認した。複数登壇者のセッションでは、発言や事例を本文中で該当する話者に結び付ける。

## 2. 根拠を読み、五つの欄に書く

各発表ページの要旨で対象・問いを把握し、章立てから検証や質疑に進む。数値には母数・対象史料・条件を付け、比較や誤読例は該当時刻の書き起こしまたは録画を確認する。書き起こしは自動生成なので、重要な数字や固有名が食い違う場合は録画に戻る。確認がつかない内容は保留する。S05は要旨と章立てを参照した。

| 原稿の欄 | 記入する内容 |
| --- | --- |
| 概要の概要 | 誰が、どんな歴史上・教育上の問いを、どの史料や実践から考えたか。 |
| 先行研究との関係 | 発表で言及された研究、方法、事業との具体的なつながり。 |
| 手法・技術の要点 | 入力史料、処理や比較、歴史家が判断した箇所。 |
| 有効性・正当性の確認 | 実演、既知事例との比較、史料照合など、発表で実際に示された根拠とその範囲。 |
| 議論の継続・未解決の課題 | 発表者の留保、失敗例、討論で残った問い。提案段階のものはその旨を明記する。 |

該当箇所がない欄は表のセルを空にする。各報告の末尾に公式ページを、具体的な結果や争点には録画の章リンクを付ける。原文の長い引用は避け、各言語の読者向けに要約する。改訂時は原稿冒頭の資料確認日も更新する。

## 3. プレビューと照合

公開サイトのリポジトリでNode.js 24を使い、初回は `npm ci` を実行する。以下を順に実行する。照合スクリプトはPython 3.9以降とBeautiful Soup 4（`python -m pip install beautifulsoup4`）を使用する。

```powershell
npm run verify
python scripts/check-conference-sources.py
```

2番目のコマンドは公式サイトから一覧と発表ページを読み、生成済みHTMLの原題・登壇者・件数と順序・目次・五つの欄・出典URL・書き起こし公開状態・録画時刻と照合する。取得済みの資料で再現する場合は、一覧を `index.html`、個別ページを公式ファイル名で同じフォルダに置き、`--source-dir フォルダ名` を追加する。内容が修正された場合は、第2段階で要約も読み直す。

生成物は `dist/notes/ai-history-2026/index.html` と `dist/en/notes/ai-history-2026/index.html`。ブラウザで日英の切り替えと目次からの移動を確認し、時刻リンクから実際の発言を確認する。修正は該当するMarkdown原稿に反映して再実行する。

## 4. 原稿確認後に公開する

サイト所有者が原稿を確認した後、この研究ノートに関係する原稿、レイアウト、研究活動ページのリンク、照合スクリプト、手順書だけをコミットする。既にある別件の編集と生成物 `dist/` はコミットの対象から外す。

`main` への反映で既存のGitHub Actionsがビルド・配信する。デプロイ完了後に [研究活動](https://ancientrome220.github.io/activities/) から [記事の公開予定先](https://ancientrome220.github.io/notes/ai-history-2026/) まで進み、目次と録画リンクを確認する。
